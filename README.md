## Research & Projects / 科研与项目

### 🛰️ Multi-Source Fusion Positioning for Challenging GNSS Environments

面向城市峡谷、室内外过渡等弱 GNSS 场景，研究高可靠连续定位方法。

- 构建 GNSS/IMU/PDR 多源融合算法框架，完成惯导误差建模与 EKF 状态更新
- 设计 **Rule-guided GRU-Rscale** 观测可信度模块
- 引入 CAD 地图可通行区域不等式约束
- 在弱信号遮挡与异常观测测试中，实现高可靠连续定位，P95 定位精度提升 **78%**
- 以第一作者身份撰写 EI 期刊论文（在投）

[View BeiDou-related code →](https://github.com/Femad-6/BeiDou-Code)

### 🦾 ESP32 Multi-Sensor Wearable Robotic Arm Control

基于 ESP32-S3、IMU 与柔性传感器构建穿戴式体感控制系统，解决手部动作与机械臂自由度匹配问题。

- 完成多通道传感器数据实时采集与动作映射
- 使用 EMA 滤波与零偏标定，将数据标准差降低 **60%**
- 实现端到端延迟 **< 150 ms** 的低延迟稳定控制
- 构建低成本、可复现的嵌入式控制系统

[View project →](https://github.com/Femad-6/Robot-arm-esp32)

### 🚚 Intelligent Logistics Route Optimization

围绕 VRP、EVRP 与 VRP-UAV 等复杂配送场景开展算法设计与 Web 应用开发。

- 研究并改进遗传算法，设计自适应适应度函数、启发式基因修补策略与多层级复合编码
- 综合考虑载重、电量、时间窗、充电行为及配送成本等约束
- 使用 Flask、Socket.IO、NumPy 与 Matplotlib 实现实时求解和结果可视化
- 已获得 **3 项软件著作权**

[EV Route Optimizer](https://github.com/Femad-6/ChargePath-Optimizer) · [UAV-Vehicle Delivery Optimization](https://github.com/Femad-6/UAV-Vehicle-Delivery-Optimization-System)
